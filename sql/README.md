# Consultas DuckDB

- `preparar_bigmac.sql` / `preparar_bigmac.py`: índice Big Mac mais recente.
- `preparar_bigmac_historico.sql` / `preparar_bigmac_historico.py`: série histórica do Big Mac.
- `preparar_hobbies.sql`: consulta do CSV YouGov.
- `preparar_expectativa.sql` / `preparar_expectativa.py`: ranking e distribuição de expectativa de vida.

Os CSVs que alimentam o D3.js estão na pasta `dados/`.
