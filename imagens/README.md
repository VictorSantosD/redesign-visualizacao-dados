# Visualizações originais

Coloque aqui as capturas das **visualizações originais** analisadas. Sugestão de nomes:

- `bigmac-original.png`
- `caso2-original.png`
- `caso3-original.png`

Os caminhos correspondentes já estão configurados em `js/<caso>/info.js`. É possível usar outro nome alterando `imagemOriginal` no respectivo arquivo.

Incluir no relatório o link de origem, a data de acesso e o contexto da visualização. Não usar uma imagem gerada ou um redesign como se fosse o original.
